# 我们自己使用：官网 API 三步开通指引

> 更新：2026-10-13｜适用：官网管理后台的合作授权页面
> 用途：给一家第三方代运营系统开通接入。官网 API 已存在，每次只需新建该合作方的授权。

## 开始前

准备合作方名称和合作截止日期，使用我们自己的管理员账号登录官网后台。

后台地址：

```text
https://huanyinai.com/admin/integrations
```

## 第一步：新建合作授权

点击 **“新建合作授权”**，填写：

- **合作方名称**：第三方公司或系统名称。
- **合作截止（本地时间，必须明确）**：按合作约定填写到期时间。

## 第二步：选运营内容和权限

在 **“授权 scope（最小权限）”** 中勾选：

- **读取内容**（content:read）。
- **创建与编辑内容**（content:write）。

在 **“资源与记录范围”** 中只勾选实际需要运营的内容，例如博客、案例、行业方案。记录 ID 留空代表所选资源的全部记录；若只允许修改指定记录，则填写其 ID。

首次接入建议保持：不勾选“发布内容”，关闭“允许机器自动发布”；媒体、线索、保护字段等权限不选。第三方先写草稿，由我们审核。

Token 有效分钟、密钥有效天数、每分钟限流等参数通常保留后台默认值；合作截止必须按实际约定核对。

## 第三步：生成密钥并交付

输入我们自己的管理员密码确认操作，点击 **“创建并显示一次密钥”**。

创建成功后：

1. 保存该合作方的 **Client ID**（合作方列表/记录中的 ID）。
2. 在 **“新密钥仅显示一次”** 区域点击 **“复制密钥”**，取得 Client Secret。
3. 将 Client ID、Client Secret 和正式 API 地址通过约定的安全渠道交给合作方，同时发送第三方对接资料 ZIP。

确认已保存密钥后再点击 **“我已保存，关闭展示”**。刷新、切换记录或关闭展示后无法再次查看原密钥；不要把我们自己的管理员密码交给第三方。

交付时用下面的格式，真实值只在安全交付渠道填写：

```text
API 地址：https://huanyinai.com/api/integrations/v1
Client ID：<创建后取得的合作方 ID>
Client Secret：<本次只显示一次的密钥>
授权内容：<本次选定的内容资源>
授权操作：读取内容、创建与编辑草稿
合作截止：<约定到期日期和时间>
请先完成一篇草稿的新增、修改与回执验证，再由我们审核。
```

配套附件：`寰引智能官网API第三方对接资料-v1.8.1.zip`。资料包不含真实凭据；无需把本内部指引发给第三方。

## 常用处理

| 情况 | 我们怎么操作 |
|---|---|
| 密钥没有保存或需要更换 | 选择合作方，点击“轮换密钥”，确认后保存新密钥并重新交付；原凭据会失效 |
| 暂时停止合作 | 点击“停用”并确认 |
| 终止授权 | 点击“撤销全部授权”并确认，原 Token 不能继续调用 |
| 延长合作或调整内容范围 | 选择合作方，修改策略，点击“复核并保存策略”，按提示确认 |

## 完成标准

合作方已出现在列表中且授权有效；密钥已安全交付；第三方收到完整对接资料。第三方实际接通仍需完成一篇草稿的联调，开通授权本身不代表联调通过。
