# v1.6.0 封板说明

> 日期：2026-09-11（Asia/Shanghai）  
> 状态：待创建 Tag 并完成最终生产验收

## 封板范围

- 官网案例、博客、八大行业方案与 AI 外贸、跨境物流内容更新。
- 内容方向每日统计与初始化基线校准。
- 首页行业短标题和客户信赖模块后台可维护化。
- SEO/GEO 动态口径、安全鉴权和标准部署回滚能力。

## 核心设计决策

- 云端服务器是生产唯一权威源，本机历史副本仅供参考。
- 内容管理优先后台数据驱动，避免新增案例或行业时修改展示代码。
- 首页信赖模块区分真实客户与典型场景；典型场景不可伪装成真实案例。
- 保持管理员与匿名访客两种角色，不引入审批流和营销数据证据状态系统。

## 数据变化

- `shared-data` 中内容、统计基线及首页客户列表发生更新，无数据库迁移。
- 首页客户信赖模块为 10 个真实客户与 5 个典型场景，按 2:1 循环展示。

## 验收门槛

- 自动化测试和正式构建通过。
- `current` 指向封板 SHA 对应 release，PM2 online、异常重启为 0。
- 内外网 `/health` 正常。
- 首页桌面和移动端无溢出，匿名/真实口径、8 个行业短标题及后台维护字段正确。
- 未登录后台写接口返回 401，默认历史密码不可登录。

## 回滚点

- 代码回滚：封板前最后一个生产 release。
- 数据回滚：使用本次变更前按目标文件创建的备份，不覆盖无关持久化数据。

## 遗留项

- 云端 `main` 与 GitHub `origin/main` 存在提交差异；正式环境不受影响，但 Tag 和提交需要成功推送后才算远端版本闭环。
- 百度验证文件为既有未跟踪生产文件，封板不得删除。
